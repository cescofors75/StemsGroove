## Inicio ultra rapido

1. Primera vez: ejecuta INSTALAR.bat (Windows) o ./instalar.sh (macOS/Linux).
2. Uso diario: ejecuta INICIAR.bat (Windows) o ./iniciar.sh (macOS/Linux).
3. Abre http://localhost:3000.
